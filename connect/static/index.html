Meet your new voice.

Connect your OmniVoice server, hear it speak, and bring it into Assist.

OmniVoice Connect · experimental 0.1.0
Your voice runs on your server. This companion runs in Home Assistant. Speech generation stays on a separate NVIDIA Docker host. You can stop this companion after setup.
01

Start with the right hardware

The GPU server needs x86-64 Linux, a supported Turing-or-newer NVIDIA GPU, a CUDA 13-compatible R580-or-newer driver and NVIDIA Container Toolkit. The companion itself needs no GPU.

Allow at least 8 GB system RAM and 20 GB storage on the server. First startup downloads model weights. Actual GPU memory needs depend on settings; the published runtime has been tested on RTX 3090.

02

Set up your server

I need to install OmniVoice

Docker uses a persistent named volume for model files and voices.

On a Linux Docker host, save the file and run docker compose up -d. On TrueNAS, paste it into Apps → Discover Apps → Custom App → Install via YAML. Grant UID/GID 568 access to the dataset first.
This reserves one GPU. With multiple GPUs, replace count: 1 with your desired device_ids. Keep the published port on your trusted LAN. Wait for the container to become healthy, then continue below.
Already running OmniVoice? Go straight to the connection check.


03
Find your voice server
Enter the external server's LAN address, not the Home Assistant address. No URL prefix is needed.
A sample sends one fixed English phrase to your server. Generated audio is held temporarily in memory and is never included in diagnostics.
Enter your server to begin.
  • ○ Server connection: not checked
  • ○ Speech generation: not checked
  • ○ Assist: awaiting your test
The sample plays here in your browser. It does not verify playback through Assist.


04
Bring it into Assist
  1. Open Wyoming setup and enter the same external address and port.
  2. In Settings → Voice assistants, edit your assistant and select OmniVoice as its text-to-speech provider.
  3. Choose its advertised language and voice. Send a request that produces a spoken response through your usual Assist device.
Open Wyoming setup ↗
If the button cannot open your instance, use Settings → Devices & services → Add integration → Wyoming Protocol.
Stopping OmniVoice Connect should leave Assist speech working: Assist connects directly to your external server.
